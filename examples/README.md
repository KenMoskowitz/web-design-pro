# Examples

Fully-rendered demos generated by `scripts/new-project.sh`. Open the `index.html` in any browser or serve locally:

```bash
cd examples/cornerstone-law && python3 -m http.server 8000
# → http://localhost:8000
```

## What's here

| Example          | Vibe            | Goal | Notes                                                          |
| ---------------- | --------------- | ---- | -------------------------------------------------------------- |
| `cornerstone-law` | premium-trust   | form | Boutique estate-planning firm, fictional. Tailwind and GSAP are vendored locally so it works offline. |

Production projects (under `projects/`) use the Tailwind CDN Play script and GSAP CDN per the SOP — no build step required.
